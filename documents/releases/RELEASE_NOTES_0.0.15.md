# Release 0.0.15: Publishing Fix (JavaDoc)

**Release Date**: January 29, 2026  
**Version**: 0.0.15

## Overview

0.0.15 is a patch release to enable Maven Central publishing by fixing JavaDoc generation errors.

## Fixed

- JavaDoc parameter/name mismatches in `ShutdownManager`
- Missing JavaDoc `@return` in `CircuitBreaker`

## Notes

Feature-wise, this release is otherwise equivalent to 0.0.14.
